# csharp-generics

This project contains exercises on C# generics, including the implementation of a generic Queue class.

## 0-queue

A generic Queue<T> class implementation that demonstrates:
- Generic class definition without inheritance
- Type checking using reflection
- Proper XML documentation
- Support for any type parameter T

The Queue class provides a `CheckType()` method that returns the name of the type parameter, making it useful for runtime type inspection.

## Files

- `0-queue/queue.cs` - Generic Queue class implementation
- `0-queue/0-queue.csproj` - Project configuration file
